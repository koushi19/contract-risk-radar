# Clause Risk Radar

A Legal NLP tool to identify and classify risk in contract clauses.

## Features
- Clause Segmentation
- Risk Classification (Safe, Review, Risky)
- reasoning String Generation
- PDF/TXT Support

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
